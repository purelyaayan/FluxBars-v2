# FluxBars v2

FluxBars v2 is a lightweight, customizable audio visualizer built for Windows. It is designed to display real-time audio spectrum bars with smooth performance and easy setup.

---

## Why FluxBars v2?

FluxBars v1 was originally built with a different approach and structure, but it started showing limitations in terms of performance, maintainability, and packaging.

For v2, I decided to switch and rebuild parts of the project using **C# (.NET / WPF)** because:

- Better performance for real-time audio processing
- Easier Windows integration
- More stable UI rendering for animations
- Simpler deployment and EXE generation
- Cleaner code structure for future updates
- Now it even works without the need of a mic

This change makes FluxBars more efficient and easier to extend in the future.

---

## Features

- 🎵 Real-time audio spectrum visualization  
- 🎨 Smooth animated bars  
- ⚡ Low CPU usage design
- - Low RAM usage than the original one(fluxbars v1)
- 🪟 Native Windows application (WPF-based UI)  
- 🔧 Easy customization of colors and bar styles  
- 📦 Can be packaged as a single EXE (no extra setup needed if published correctly)
